# دليل Super Admin — Dar3a Store

## الدخول الآمن

1. افتح `/admin.html`.
2. أدخل اسم المستخدم وكلمة المرور التي أنشئت بواسطة `npm run bootstrap-admin`.
3. الجلسة تُخزن في Cookie آمن فقط؛ لا تستخدم المتصفح لحفظ أو مشاركة كلمة المرور.
4. استخدم **خروج** عند انتهاء الجلسة، خصوصاً على جهاز مشترك.

هذه الصفحة مخصصة لدور `super_admin`. حساب `developer` يستخدم [`../public/developer.html`](../public/developer.html).

## أقسام لوحة التحكم

- **لوحة المعلومات:** ملخص المنتجات والطلبات والمشتركين.
- **المنتجات والمخزون:** إضافة المنتجات، تعديلها، ومتابعة الكميات المنخفضة.
- **الكوبونات:** إنشاء خصم ثابت أو نسبة وحد أدنى للطلب.
- **الطلبات:** مراجعة الطلبات التي نجحت في الحفظ قبل فتح WhatsApp للعميل.
- **المشتركين:** إدارة القائمة البريدية.
- **الإعدادات:** اسم المتجر وشعاره وعملة المتجر وأرقام التواصل وWhatsApp.
- **مستخدمو النظام:** إنشاء حسابات Super Admin أو Admin أو Developer وإيقاف الحسابات.

## الصلاحيات

| الدور | الصلاحية |
|---|---|
| `super_admin` | لوحة التحكم كاملة وإدارة الحسابات |
| `admin` | الوصول الخادمي المصرح للطلبات وتحديث حالتها |
| `developer` | بوابة المطور للاشتراكات والتفعيل |

لا تشارك حساب Super Admin. أنشئ لكل مسؤول حساباً منفصلاً وأوقف الحساب فور انتهاء الحاجة إليه.

## صفحة المطور والتفعيل

من قائمة **بوابة المطور** أو مباشرة `/developer.html`:

1. أنشئ سجل العميل بالنطاق الفعلي فقط.
2. اضغط تفعيل عند بدء الاشتراك السنوي.
3. انسخ مفتاح التفعيل فور ظهوره؛ النظام لا يستطيع عرضه لاحقاً.
4. راقب تاريخ الانتهاء وآخر تفعيل وعدد التحقق.
5. جدّد سنة أو أوقف/ألغِ الاشتراك حسب الاتفاق.

## نصائح تشغيلية

- السعر الذي يراه العميل ليس مصدراً موثوقاً؛ راجع المجموع المسجل في الطلب.
- لا تحذف المنتجات التي لها طلبات تاريخية دون تصدير سجلاتك أولاً.
- غيّر كلمة مرور أي حساب مشتبه به من قسم مستخدمي النظام.
- استخدم اتصال HTTPS فقط، وراجع [قائمة التسليم](DELIVERY_CHECKLIST.md) قبل الإطلاق.
