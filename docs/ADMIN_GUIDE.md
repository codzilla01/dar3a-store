# دليل لوحة الإدارة — Dar3a Store

## الدخول الآمن

1. افتح `/admin.html`.
2. أدخل اسم المستخدم وكلمة المرور لحساب `developer` أو `admin`.
3. الجلسة محفوظة في Cookie آمن فقط؛ لا تحفظ كلمة المرور في المتصفح.
4. استخدم زر **خروج** عند انتهاء العمل، خصوصاً على جهاز مشترك.
5. حساب `developer` يستطيع، بعد أول دخول بكلمة المرور، اختيار **دخول ببصمة الجهاز**. تبقى كلمة المرور مطلوبة كطريقة بديلة دائماً.

أنشئ أول حساب Developer بواسطة:

```bash
npm run bootstrap-developer -- developer '<كلمة-مرور-قوية>' 'Store Developer'
```

## الدوران والصلاحيات

| الدور | الصلاحيات |
|---|---|
| `developer` | تحكم كامل بالمتجر، إدارة الحسابات، بوابة الاشتراكات السنوية، التفعيل والتجديد والإيقاف والإلغاء |
| `admin` | إدارة المنتجات والأصناف والمخزون والطلبات والكوبونات والإعدادات والمشتركين، وتغيير كلمة مرور حسابه فقط |

لا توجد أدوار أخرى في النسخة الإنتاجية. الحسابات القديمة ذات دور `super_admin` تتحول تلقائياً إلى `developer` عند تنفيذ تحديث قاعدة البيانات.

## أقسام لوحة الإدارة

- **لوحة المعلومات:** ملخص المتجر والطلبات والمنتجات والمشتركين.
- **المنتجات والمخزون:** إضافة المنتجات وتعديلها ومتابعة الكميات.
- **الكوبونات:** إنشاء الخصومات وإدارتها.
- **الطلبات:** مراجعة الطلبات التي تم حفظها قبل فتح WhatsApp وتحديث حالتها.
- **المشتركين والإعدادات:** إدارة النشرة وبيانات المتجر والتواصل.
- **حسابي وكلمة المرور:** متاح للدورين. أدخل كلمة المرور الحالية ثم كلمة مرور جديدة لا تقل عن 12 حرفاً وتحتوي حروفاً وأرقاماً.
- **مستخدمو النظام:** يظهر للمطور فقط لإنشاء أو إيقاف حسابات Developer وAdmin.

## دخول Developer ببصمة / Passkey الجهاز

هذه الميزة متاحة لـ `developer` فقط وليست لحسابات `admin`:

1. استخدم كلمة مرور Developer للدخول الأول، ثم افتح `/developer.html`.
2. من **بصمة هذا الجهاز** اكتب اسماً يعرف الجهاز واضغط **تفعيل بصمة هذا الجهاز**، ثم أكمل Face ID أو Touch ID أو Windows Hello أو بصمة Android أو PIN الذي يطلبه الجهاز.
3. عند الدخول لاحقاً اكتب اسم مستخدم Developer واختر **دخول ببصمة الجهاز**. لا يلزم إدخال كلمة المرور في ذلك الدخول، لكنها تبقى وسيلة الاسترداد الأساسية.
4. من قائمة الأجهزة المسجلة أزل أي جهاز مفقود أو قديم فوراً. إزالة آخر جهاز لا تمنع الدخول بكلمة المرور.
5. إذا ظهرت رسالة أن بصمة المنصة غير متاحة، استخدم كلمة المرور أو متصفحاً حديثاً على جهاز يوفر قفل جهاز. لا يمكن تفعيلها على HTTP؛ يلزم HTTPS في الإنتاج.

لا تخزن Dar3a Store بصمة أو صورة وجه أو PIN. يصدر الخادم تحدياً قصير العمر ويحفظ المفتاح العام فقط بعد أن يتحقق الجهاز محلياً.

## بوابة الاشتراكات والتفعيل

صفحة `/developer.html` متاحة لدور `developer` فقط:

1. أنشئ اشتراكاً سنوياً للنطاق الفعلي للعميل.
2. فعّل الاشتراك بعد استلام الدفعة.
3. انسخ مفتاح التفعيل عند ظهوره؛ لا يعرض النظام المفتاح لاحقاً.
4. راقب تاريخ الانتهاء وآخر تحقق وعدد التحققات.
5. استخدم التجديد أو الإيقاف أو الإلغاء بحسب الاتفاق مع العميل.

## نصائح تشغيلية

- لا تشارك حساب Developer؛ أنشئ حساب Admin منفصلاً لكل موظف متجر.
- السعر والمخزون يُحسبان من الخادم، لذلك راجع الطلب المحفوظ لا السعر المرسل من المتصفح.
- أوقف حساب Admin فور انتهاء صلاحية الموظف.
- استخدم HTTPS فقط وراجع [قائمة التسليم](DELIVERY_CHECKLIST.md) قبل الإطلاق.
