# 👑 دليل لوحة التحكم — Admin Guide

## الدخول إلى لوحة التحكم

| الطريقة | الخطوات |
|---|---|
| 🖱️ الضغط المطوّل | من الصفحة الرئيسية، اضغط مطولاً على **شعار المتجر** لمدة 3 ثوانٍ — يظهر شريط تقدم ثم تُفتح نافذة الدخول |
| ⌨️ اختصار | اضغط `Ctrl + Shift + A` |
| 🔗 رابط | أضف `?admin` إلى رابط المتجر |

ثم:
1. اختر الدور: **👑 مدير** أو **👥 مساعد**.
2. اضغط **"طلب كود التحقق"** — يصل كود من 6 أرقام إلى تيليجرام.
3. أدخل الكود (صالح 5 دقائق) — يمكنك لصق الكود كاملاً في أي خانة.

## الأقسام

### 📊 لوحة المعلومات
نظرة عامة على: عدد المنتجات، الطلبات، المشتركين، والإيرادات التقديرية.

### 📦 إدارة المحتوى
- عرض كل المنتجات مع فلترة حسب النوع.
- تعديل السعر/المخزون/الحذف السريع.
- **إضافة / تعديل منتج**: الاسم، النوع، السعر، البراند، الصورة، الوصف، المواصفات (specs)، المخزون.
- **المخزون**: متابعة الكميات وتقليلها عند البيع.

### 🎮 الألعاب وقطع PC
- **PC Games / PlayStation**: إدارة ألعاب المنصات.
- **قطع PC**: أضف القطع (معالج، لوحة أم، كرت شاشة، رام، تخزين، مزود طاقة، صندوق) — تظهر تلقائياً في **منشئ التجميعات** بالمتجر.

### 🏷️ الكوبونات
- إنشاء كوبون: `CODE` + نوع الخصم (نسبة % / مبلغ ثابت) + الحالة.
- تُطبَّق الكوبونات في عمليات البيع حسب إعداداتك.

### 📜 الطلبات
كل طلب يُنشأ من شاشة "إتمام الطلب" في المتجر يظهر هنا مع:
اسم العميل، الهاتف، العنوان، طريقة الدفع، الملاحظات، والمنتجات.

### ⚙️ الإعدادات
| الإعداد | الوصف |
|---|---|
| اسم المتجر / التاغلاين | يظهر في الهيدر وHero وtitle |
| العملة | مثال: `ج.س` |
| الهاتف / واتساب | رقم التواصل (استخدم الصيغة `09...` أو `249...`) |
| العنوان / ساعات العمل | يظهران في الفوتر |
| اللون الأساسي | يغيّر هوية الموقع كاملاً فوراً |
| الشعار / الفافيكون | رابط صورة أو اتركه افتراضياً |
| تذييل المطور | اسم ورابط المطور |

### 📧 النشرة البريدية
عرض المشتركين، حذف فردي، أو مسح الكل.

## نصائح سريعة

- 💾 **احفظ دائماً** بعد أي تعديل (زر الحفظ أعلى كل قسم).
- 🔄 تغييرات المنتجات تنعكس على المتجر خلال ثوانٍ (مزامنة تلقائية كل 15 ثانية).
- 📱 لوحة التحكم تعمل على الجوال — زر القائمة يفتح الشريط الجانبي.
- 🚪 زر **"خروج"** في أعلى الشريط الجانبي ينهي الجلسة فوراً.
