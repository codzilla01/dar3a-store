# ✅ قائمة التسليم والتشغيل الأولى — Delivery Checklist

> اتبع هذه القائمة حرفياً عند استلام المشروع — ستحتاج **30 دقيقة فقط** للتشغيل الكامل.

## أولاً: قبل أي شيء (5 دقائق)

- [ ] استلمت الملفات/المستودع كاملاً.
- [ ] **دوّرت الأسرار القديمة** (إذا كانت نسخة قديمة نُشرت من قبل):
  - [ ] أنشئ بوت تيليجرام جديد عبر [@BotFather](https://t.me/BotFather) (أو نفّذ `/revoke` للتوكن القديم).
  - [ ] في Supabase: **Settings → API → Rotate** للمفاتيح.
  - [ ] ولّد سر JWT جديداً: `openssl rand -hex 32`.
- [ ] أنشئ حسابات: [GitHub](https://github.com) + [Vercel](https://vercel.com) + [Supabase](https://supabase.com).

## ثانياً: قاعدة البيانات (10 دقائق)

- [ ] أنشئ مشروعاً جديداً في Supabase.
- [ ] افتح **SQL Editor** ← الصق محتوى [`../supabase/schema.sql`](../supabase/schema.sql) ← **Run**.
- [ ] انسخ من **Settings → API**:
  - [ ] Project URL
  - [ ] anon key (أو service_role key)

## ثالثاً: التشغيل المحلي — للاختبار (5 دقائق)

- [ ] `cp .env.example .env` ثم ضع القيم الحقيقية.
- [ ] `npm install`
- [ ] `npm start` → افتح http://localhost:3000
- [ ] جرّب: تصفح المنتجات، أضف للسلة، إتمام الطلب، البحث (Ctrl+K)، تبديل الثيم.
- [ ] **بدون Supabase؟** — يعمل المتجر في وضع تجريبي بمنتجات نموذجية (لا تحفظه للإنتاج).

## رابعاً: النشر على Vercel (10 دقائق)

- [ ] ارفع الكود إلى GitHub (بدون ملف `.env` — `.gitignore` يتولى ذلك).
- [ ] Vercel ← **New Project** ← استورد المستودع.
- [ ] **Settings → Environment Variables** ← أضف كل متغيرات `.env.example` بقيمها الحقيقية.
- [ ] **Deploy** ✅
- [ ] افتح الرابط المنتَج وتأكد أن كل شيء يعمل.

## خامساً: إعداد المتجر (10 دقائق)

- [ ] ادخل لوحة التحكم (اضغط مطولاً على الشعار 3 ثوانٍ ← طلب كود ← الكود يصلك على تيليجرام).
- [ ] من **الإعدادات**: غيّر اسم المتجر، الشعار، اللون الأساسي، أرقام التواصل، العملة.
- [ ] أضف منتجاتك الحقيقية (افحص/سلسلة/برامج/ألعاب/قطع PC).
- [ ] أنشئ كوبون خصم تجريبي وجرّبه.
- [ ] تأكد أن روابط **واتساب** و**فيسبوك** و**تيك توك** في الفوتر تشير لحساباتك.

## سادساً: ما بعد التسليم

- [ ] فعّل النطاق الخاص (Domain) من Vercel ← Settings ← Domains.
- [ ] راجع سياسات الخصوصية/الشروط وعدها لتناسب نشاطك المحلي.
- [ ] احتفظ بملف `.env` في مكان آمن (كلود خاص وليس في Git).
- [ ] راجع [`../README.md`](../README.md) لتفاصيل API والتخصيص.

---

### 🆘 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| المنتجات لا تظهر | تأكد من تنفيذ `schema.sql` وصحة `SUPABASE_URL` و المفتاح في Vercel |
| كود OTP لا يصل | تأكد من `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` وأن البوت أرسل لك /start |
| زر "إتمام الطلب" لا يفتح واتساب | تحقق من رقم واتساب في الإعدادات (الصيغة الدولية `249...`) |
| خطأ 500 في API | افتح Vercel ← Functions Logs وتحقق من رسالة الخطأ |
| صور المنتجات لا تظهر | تأكد من روابط الصور (استخدم روابط مباشرة أو ارفع الصور عبر لوحة التحكم) |
