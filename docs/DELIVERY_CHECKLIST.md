# قائمة تسليم Dar3a Store الإنتاجية

## قبل النشر

- [ ] تم تنفيذ [`../supabase/schema.sql`](../supabase/schema.sql) مرة واحدة في مشروع Supabase الخاص بالعميل.
- [ ] تمت إزالة/مراجعة أي سياسات RLS قديمة عامة؛ الـ schema يغلق وصول `anon` و`authenticated`.
- [ ] تم إنشاء `ADMIN_JWT_SECRET` جديد بطول 32 حرفاً على الأقل.
- [ ] تم ضبط `SUPABASE_URL` و`SUPABASE_SERVICE_KEY` و`ADMIN_JWT_SECRET` في Vercel فقط.
- [ ] لم تُضف مفاتيح Supabase أو كلمة مرور أو ملف `.env` إلى Git.
- [ ] لا يوجد `ALLOW_DEMO_MODE` أو `DEMO_*` في بيئة Vercel.

## أول حسابات الإدارة

- [ ] محلياً، وبعد إعداد `.env`: نفّذ `npm run bootstrap-admin -- <username> <password> <display-name>`.
- [ ] ادخل إلى `/admin.html` بالحساب الناتج.
- [ ] أنشئ حساب `developer` مستقلاً من **مستخدمو النظام**.
- [ ] اختبر كلمة مرور خاطئة، ثم اختبر تسجيل الخروج.
- [ ] أنشئ حساباً تجريبياً وأوقفه، وتأكد أنه لا يستطيع استدعاء API المحمي.

## إعداد المتجر

- [ ] غيّر اسم المتجر والشعار والألوان وأرقام الهاتف وWhatsApp من Super Admin.
- [ ] أضف المنتجات المرخصة الحقيقية واضبط المخزون والأسعار.
- [ ] أضف كوبوناً تجريبياً ثم اختبره في طلب حقيقي.
- [ ] راجع الروابط الاجتماعية وسياسة الخصوصية والشروط والاسترجاع.

## اختبار الطلب عبر WhatsApp

- [ ] أنشئ طلباً تجريبياً من واجهة المتجر.
- [ ] تحقق أن رسالة WhatsApp لا تُفتح إذا فشل حفظ الطلب.
- [ ] تحقق أن إجمالي الطلب في الرسالة يطابق المجموع المحفوظ في لوحة الإدارة.
- [ ] تحقق أن المخزون نقص بالكمية الصحيحة.
- [ ] جرّب كمية أكبر من المخزون وتأكد أن الخادم يرفض الطلب.

## الاشتراك والتفعيل

- [ ] افتح `/developer.html` بحساب Developer.
- [ ] أنشئ اشتراكاً سنوياً للنطاق الصحيح.
- [ ] فعّل الاشتراك واحفظ مفتاح التفعيل المعروض مرة واحدة في مدير كلمات مرور.
- [ ] اختبر `POST /api/license/verify` بالمفتاح والنطاق الصحيحين.
- [ ] جدّد الاشتراك، ثم اختبر الإيقاف والإلغاء في حساب تجريبي.
- [ ] تحقق من ظهور تاريخ الانتهاء وآخر تحقق وعدد التحقق في بوابة المطور.

## قبول النشر

- [ ] `npm ci && npm run check && npm test` نجحت محلياً.
- [ ] `npm audit --omit=dev --audit-level=high` لا يعرض ثغرات عالية أو حرجة.
- [ ] تم النشر على Vercel واختبار `/api/health`؛ يجب أن يعرض `database: "supabase"`.
- [ ] تم ربط نطاق العميل وHTTPS.
- [ ] تم اختبار صفحات `/`, `/admin.html`, `/developer.html` على الهاتف وسطح المكتب.
- [ ] تم حفظ نسخة احتياطية من إعدادات العميل وخطة استعادة Supabase.
