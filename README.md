# 🛡️ Dar3a Store — درعة ستور

**متجر إلكتروني متكامل جاهز للتشغيل والتسليم** — أفلام • مسلسلات • برامج هندسية • ألعاب • تجميعات PC

## ✨ نظرة عامة

متجر إلكتروني عربي (RTL) بواجهة عصرية فاخرة، مبني بأسلوب يعمل مباشرة على **Vercel** مع **Supabase** كقاعدة بيانات، ولوحة تحكم كاملة مع مصادقة عبر **Telegram OTP**، ومساعد ذكي باللهجة السودانية.

### 🎯 المميزات الرئيسية

| القسم | المميزات |
|---|---|
| 🏪 **واجهة المتجر** | ثيم داكن/فاتح، Hero متحرك، إحصائيات، شريط مميزات، بطاقات منتجات بشارات ومخزون |
| 🔍 **البحث** | بحث عالمي فوري (Ctrl+K) مع نتائج حية وعرض المفضلة |
| 🛒 **التسوق** | سلة جانبية، مفضلة، حركة طيران للسلة، مودال تفاصيل المنتج، شراء مباشر عبر واتساب |
| 💳 **الدفع** | شاشة إتمام طلب كاملة (اسم/هاتف/عنوان/طريقة دفع/ملاحظات) + إرسال الطلب لواتساب وحفظه في القاعدة |
| 🖥️ **تجميع PC** | منشئ تجميعات تفاعلي (معالج، لوحة، كرت شاشة، رام، تخزين...) مع ملخص فوري |
| 👑 **لوحة التحكم** | إدارة المنتجات/المخزون/الكوبونات/الطلبات/الإعدادات/النشرة البريدية — مع أدوار (مدير/مساعد) |
| 🤖 **المساعد الذكي** | شات بوت باللهجة السودانية يجيب عن الأسئلة ويقترح المنتجات |
| 📱 **الجوال** | تنقل سفلي (Bottom Nav)، تصميم متجاوب بالكامل، هياكل تحميل متحركة |
| 🚀 **الأداء** | صور كسولة، هياكل Skeleton، مزامنة ذكية (إعادة رسم فقط عند التغيير)، PWA Manifest |
| 🔍 **SEO** | Meta كاملة، Open Graph، Twitter Cards، JSON-LD، صفحة 404 مخصصة |
| ♿ **إتاحة الوصول** | Skip link، Focus styles، دعم prefers-reduced-motion، ARIA labels |

## 🏗️ البنية التقنية

```
dar3a-store/
├── index.js            # 🧠 واجهة API الرئيسية (Express) — يُشغَّل على Vercel ومحلياً
├── database.js         # 🗄️ طبقة Supabase (المنتجات/الإعدادات/الطلبات/الجلسات...)
├── fallback-db.js      # 🎮 وضع العرض التجريبي (ذاكرة محلية + بيانات تجريبية) عند غياب Supabase
├── server.js           # 💻 تشغيل محلي (npm start)
├── public/             # 🌐 الواجهة الأمامية (ما يتم نشره على Vercel)
│   ├── index.html      #    واجهة المتجر (HTML/CSS/JS مدمج)
│   ├── admin.html      #    لوحة التحكم
│   ├── chat-bot.html   #    المساعد الذكي
│   ├── 404.html        #    صفحة الخطأ المخصصة
│   ├── manifest.webmanifest
│   └── images/
├── api/                # 📦 طبقة Serverless بديلة/للتعمّق (غير مستخدمة في النشر الحالي)
├── supabase/schema.sql # 📜 هيكل قاعدة البيانات الجاهز للتنفيذ
├── vercel.json         # ▲️ إعدادات النشر
├── .github/workflows/  # 🤖 فحوصات CI تلقائية (Syntax + Security)
├── .env.example        # 🔑 متغيرات البيئة المطلوبة
└── docs/               # 📚 توثيق إضافي للتسليم
```

### 🔄 مسار البيانات

```
المتصفح (public/) ──fetch──▶ /api/* ──▶ index.js (Express) ──▶ database.js ──▶ Supabase
                                            │
                                            └─ (بدون Supabase) ─▶ fallback-db.js (وضع تجريبي)
```

> ✅ **مصدر وحيد للحقيقة**: كل الواجهة الأمامية داخل `public/` فقط — لا نسخ مكررة.
> ✅ **CI تلقائي**: كل دفعة تمر بفحص صياغة الكود + منع الأسرار المضمّنة.

## 🚀 التشغيل السريع

### 1) محلياً — بدون أي إعداد (وضع العرض التجريبي)

```bash
npm install
npm start
# افتح http://localhost:3000
```

> ✅ يعمل فوراً بمنتجات تجريبية داخلية — مثالي للعرض على العميل قبل ربط قاعدة البيانات.

### 2) محلياً — مع Supabase الحقيقي

```bash
cp .env.example .env
# ضع قيم SUPABASE_URL و SUPABASE_ANON_KEY (و غيرها) في .env
npm install
npm start
```

### 3) النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. استورد المستودع في [Vercel](https://vercel.com/new).
3. أضف متغيرات البيئة من **Settings → Environment Variables** (انظر الجدول أدناه).
4. Deploy — وانتهى! 🎉

### متغيرات البيئة المطلوبة

| المتغير | مطلوب | الوصف |
|---|---|---|
| `SUPABASE_URL` | ✅ | رابط مشروع Supabase |
| `SUPABASE_ANON_KEY` | ✅ | مفتاح anon (أو استخدم SERVICE_KEY) |
| `SUPABASE_SERVICE_KEY` | ✅* | مفتاح service_role (يُفضَّل للخادم) |
| `ADMIN_JWT_SECRET` | ✅ | سر توقيع JWT — ولّد بـ `openssl rand -hex 32` |
| `TELEGRAM_BOT_TOKEN` | ✅ | توكن بوت تيليجرام (لأكواد دخول الإدارة) |
| `TELEGRAM_CHAT_ID` | ✅ | معرّف دردشة المدير |
| `TELEGRAM_ASSISTANT_TOKEN` | ⬜ | توكن بوت دور "المساعد" (اختياري) |
| `TELEGRAM_ASSISTANT_CHAT_ID` | ⬜ | دردشة المساعد (اختياري) |

> *يكفي أحد المفتاحين. **⚠️ لا تضع أي من هذه القيم في الكود — كلها تُقرأ من متغيرات البيئة فقط.**

## 🗄️ إعداد قاعدة البيانات (Supabase)

1. أنشئ مشروعاً جديداً في [supabase.com](https://supabase.com).
2. افتح **SQL Editor** ونفّذ ملف [`supabase/schema.sql`](supabase/schema.sql) بالكامل.
3. انسخ **Project URL** و **anon key** إلى متغيرات البيئة.
4. أضف أول منتجاتك من لوحة التحكم.

## 👑 لوحة التحكم

### طرق الدخول (السري!)

| الطريقة | الكيفية |
|---|---|
| الضغط المطوّل | اضغط مطولاً على **شعار المتجر** (3 ثوانٍ) في الصفحة الرئيسية |
| اختصار لوحة المفاتيح | `Ctrl + Shift + A` |
| رابط مباشر | أضف `?admin` إلى نهاية رابط المتجر |

ثم اختر الدور (**مدير** / **مساعد**) واطلب كود التحقق — يصل الكود إلى تيليجرام خلال ثوانٍ.

### الصلاحيات

- **👑 مدير**: وصول كامل — منتجات، إعدادات، كوبونات، طلبات، حذف.
- **👥 مساعد**: إدارة المحتوى والطلبات دون إعدادات النظام.

## 🔒 ملاحظات أمنية مهمة — للمشتري

1. **دوّر الأسرار قبل/بعد النقل**: هذا المستودع نُظِّف من كل الأسرار المضمّنة، لكن إذا كانت نسخة قديمة منه قد نُشرت، فاعتبر مفاتيح **Supabase** و **Telegram Bot** و **JWT Secret** مسرَّبة و**أعِد توليدها من جديد** (BotFather → `/revoke`، Supabase → Rotate keys، وسر JWT جديد).
2. فعّل **RLS** على جداول Supabase حسب احتياجك (ملف `schema.sql` يفعّله بسياسة مفتوحة للبداية).
3. أضف **rate limiting** على `/api/auth/*` عند التوسع (مثل Vercel WAF أو middleware).
4. غيّر أرقام التواصل والحسابات الاجتماعية لعلامتك التجارية.
